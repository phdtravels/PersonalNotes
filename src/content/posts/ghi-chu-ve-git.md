Đây là vài lệnh tôi thường dùng khi cập nhật blog này.

```bash
git status
git add .
git commit -m "journal: ghi chép hôm nay"
git push
```

## Khi muốn xem lịch sử

```bash
git log --oneline -5
```

Tôi thích cảm giác mỗi commit là một dấu mốc nhỏ.
